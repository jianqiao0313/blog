- 修改后 `pnpm build`（含 Astro 检查）、`pnpm lint`、`pnpm format:check`、`git diff --check` 均通过。Astro 检查为 0 errors / 0 warnings / 0 hints；Vite 仍提示既有大 JS chunk，可参考下方媒体加载优化。独立代码复核通过。
- 构建产物复验：sitemap 不再包含 `/search/`，4 篇文章的重复 `og:type` 已消除，首页关于链接为 `/about/`。本报告记录发布前的审查结果；发布状态以对应 GitHub Actions 运行和线上复验为准。

报告最后更新于 2026-09-14，本次读取于 2026-09-17。已收录示例中确认：首页、`/about/`、全部 4 篇现有文章、`/posts/`、`/tags/`、`/archives/`、Git/Linux 标签页及评论服务首页。AE-20 网址检查也明确显示“网址已收录到 Google”；它的视频索引状态与普通网页索引状态不同。

评论 API / RSS 位于独立的 `comments.lvjianqiao.com` 服务。博客中的 `src/utils/waline.ts` 仅配置服务地址，不能假定修改博客 robots 或页面配置即可控制该服务的索引行为。

线上抽查确认：robots、sitemap、搜索页和 AE-20 文章返回 200；`/about` 跳到 `/about/`，canonical 一致；已删除的 Nuxt 文章返回真实 404。没有证据表明现有文章被 robots、noindex 或错误 canonical 阻止收录。三个未收录标签页分别只有对应文章列表，Google 可自行决定是否收录，不能承诺修改后立即收录。

处理依据：[Google 网页索引说明](https://support.google.com/webmasters/answer/7440203)明确允许已删除且无替代内容的页面返回 404，也说明“已抓取但未编入索引”不需要重复提交；[Google 视频索引说明](https://support.google.com/webmasters/answer/9495631)要求观看页以单个视频为主要内容；sitemap 排除方式依据 [Astro 官方 filter 文档](https://docs.astro.build/en/guides/integrations-guide/sitemap/#filter)。

## 四项性能优化复验

本节更新上方对应的四项待办；Waline 统计调度和 OSS 上传顺序未纳入此次修改。

- 图片：已为 3 篇图文的 16 处图片引用补齐真实 width/height（15 个不同图片）。尺寸存于本地清单，并作为 Markdown 插件参数参与 Astro 配置缓存判断；更新清单会使旧文章 HTML 缓存失效。桌面与 375px 视口检查均保持响应式显示。
- 导航：文章增强脚本及返回顶部按钮改为一次加载的模块，按页面初始化和清理。浏览器连续切换 4 次文章，document scroll 监听始终为 2；离开文章到首页后为 0。标题链接、复制按钮、进度条没有重复，灯箱 Escape 可关闭并释放滚动锁。
- 媒体：播放器库和 CSS 在接近视口 400px 时动态加载；两个入口脚本合计 2,852 字节（gzip 合计 1,605 字节），库本身体积不变。浏览器初始未请求屏外 APlayer，滚动接近后才下载并初始化；媒体 preload 为 none。原生控件/嵌入源链接保留为加载失败时的入口，过期异步任务不再挂载。
- 搜索：生产构建前清除旧开发索引，生成后完整替换 public/pagefind。连续构建均为 17 个文件、1 份 metadata、4 个 fragment，文件名及内容一致；生产预览和开发模式均能搜索到 Git 文章。线上 OSS 中历史哈希资源的保留策略没有改变。
- 验证：24 项 Node 回归测试、ESLint、Prettier、Astro check/build 和独立代码复核通过。Astro 为 0 errors / 0 warnings，2 条测试代码风格 hints；既有第三方构建注释和大 chunk 提示仍存在。未使用此次局部验证声称 Core Web Vitals 分数提升。
